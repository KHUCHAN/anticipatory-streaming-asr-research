# Legacy 20M streaming Zipformer decoder initialization repair

Status: completed and verified on 2026-11-15. Corrected WER is 3.56/10.97% on 400 dev-clean + 400 dev-other, versus 23.71/32.35% with incompatible padding. Complete cost is 4.390/4.387ms per chunk versus the remeasured teacher's 9.262/9.261ms. All 800 token sequences/chunk counts agree with the independent native engine plus the compatibility wrapper. [Full correction report](../../docs/small_zipformer_reproduction_2026-11-15.md). Original A2 results remain preserved as historical, incorrect operating points for this small baseline; teacher/student numbers are unchanged.

The legacy exported prediction network expects a blank-filled initial token context, `[0, 0]`, matching the original icefall ONNX decoder example. Our original adapter and current sherpa-onnx native greedy decoder both initialize with `[-1, 0]`. This legacy ONNX `Gather` treats `-1` as vocabulary ID 499 rather than blank padding. Its output is exactly equal to `[499, 0]`, and differs from `[0, 0]` by a maximum absolute 5.0068. That produces persistent initial blank decisions or missing prefixes on some utterances. Agreement between two engines sharing the incompatible convention did not establish correctness.

`reproduce.py` changes only the small model's initial token context. Its original learned graphs and acoustic-cache initialization remain untouched. The 66M teacher's decoder convention remains unchanged. `patch_decoder.py` also creates a local ONNX input wrapper mapping negative padding to blank, preserving every original learned initializer. This lets unmodified native sherpa-onnx exercise the legacy contract independently. The wrapper output exactly matches the original decoder with explicit blank inputs on initial/partial/random valid contexts. Do not apply this workaround indiscriminately to other models.

Feature scale, tail, chunk size, model weights and text normalization stay fixed. Full evaluation uses the same 400 dev-clean + 400 dev-other role as A2, CPU batch 1 and one thread, with two reversed-order full/small repetitions and excluded warmup. Independent native decoding with the wrapper checks all 800 token sequences/chunk counts. Different development/test splits prevent claiming numerical equality with the source card's test benchmark.

The frozen A2 source and its original small-model weights are never modified. New raw outputs/wrapper live in `runs/small_zipformer_reproduction_v1/`; public artifacts contain aggregate diagnostics and results only.

Sources: [icefall original ONNX greedy initialization](https://github.com/k2-fsa/icefall/blob/master/egs/librispeech/ASR/pruned_transducer_stateless7_streaming/onnx_pretrained.py), [current sherpa-onnx initialization](https://github.com/k2-fsa/sherpa-onnx/blob/master/sherpa-onnx/csrc/online-transducer-greedy-search-decoder.cc), [source model card](https://huggingface.co/desh2608/icefall-asr-librispeech-pruned-transducer-stateless7-streaming-small).
